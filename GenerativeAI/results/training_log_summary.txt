二、模型架构与规模
================================================================================

1. VAE (变分自编码器)
   ---------------------------------------------------------------------------
   架构类型: 全连接网络
   编码器: Linear(784→256) → ReLU → Linear(256→128) → ReLU
   潜在空间: fc_mu(128→32), fc_logvar(128→32)
   解码器: Linear(32→128) → ReLU → Linear(128→256) → ReLU → Linear(256→784) → Sigmoid
   总参数量: 约 253,648 (0.25M)
   潜在维度: 32
   输入尺寸: 28x28 (784维)

2. DCGAN (深度卷积生成对抗网络)
   ---------------------------------------------------------------------------
   生成器 (Generator):
     ConvTranspose2d(100→512, 4x4) → BN → ReLU
     ConvTranspose2d(512→256, 4x4) → BN → ReLU
     ConvTranspose2d(256→128, 4x4) → BN → ReLU
     ConvTranspose2d(128→3, 4x4) → Tanh
     生成器参数量: 3,448,576 (3.45M)

   判别器 (Discriminator):
     Conv2d(3→128, 4x4) → LeakyReLU(0.2)
     Conv2d(128→256, 4x4) → BN → LeakyReLU(0.2)
     Conv2d(256→512, 4x4) → BN → LeakyReLU(0.2)
     Conv2d(512→1, 4x4) → Sigmoid
     判别器参数量: 2,637,312 (2.64M)

   总参数量: 6,085,888 (6.09M)
   噪声维度: 100
   输出尺寸: 32x32x3

3. Diffusion Model (扩散模型)
   ---------------------------------------------------------------------------
   架构类型: UNet2DModel
   配置:
     - sample_size: 32
     - in_channels: 3
     - out_channels: 3
     - layers_per_block: 2
     - block_out_channels: (64, 128, 256)
     - down_block_types: (DownBlock2D, DownBlock2D, AttnDownBlock2D)
     - up_block_types: (AttnUpBlock2D, UpBlock2D, UpBlock2D)
   总参数量: 15,724,931 (15.72M)
   扩散步数: 1000 (DDPMScheduler)
   推理步数: 50-100

五、评估结果
================================================================================

评估配置:
  - 评估框架: Inception v3 (预训练ImageNet)
  - 真实数据: CIFAR-10 测试集 (1000 样本)
  - 生成样本数: 500-512 per model
  - 评估指标: FID, IS, Precision, Recall

评估结果汇总:
  ┌─────────────┬────────────┬─────────────┬─────────────┬─────────────┐
  │ 模型         │ FID ↓      │ IS ↑        │ Precision   │ Recall      │
  ├─────────────┼────────────┼─────────────┼─────────────┼─────────────┤
  │ VAE         │ 1472.65    │ 2.23±0.10  │ 0.0767      │ 0.0000      │
  │ DCGAN       │ 351.53     │ 3.61±0.41  │ 0.4000      │ 0.7033      │
  │ Diffusion   │ 978.10     │ 2.03±0.06  │ 0.8100      │ 0.0000      │
  └─────────────┴────────────┴─────────────┴─────────────┴─────────────┘

结果解读:
  - FID (Fréchet Inception Distance):
    * DCGAN最低 (351.53)，生成图像分布最接近真实分布
    * Diffusion次之 (978.10)
    * VAE最高 (1472.65)，可能受MNIST/CIFAR跨域影响

  - IS (Inception Score):
    * DCGAN最高 (3.61)，图像质量和多样性最好
    * VAE次之 (2.23)
    * Diffusion最低 (2.03)，但Precision最高

  - Precision/Recall:
    * Diffusion的Precision最高 (0.81)，生成样本质量最稳定
    * DCGAN的Recall最高 (0.70)，覆盖真实分布范围最广
    * VAE的Precision和Recall都较低

七、关键发现与结论
================================================================================

1. 模型规模与性能关系:
   - VAE (0.25M参数): 最小规模，FID最高 (1472.65)
   - DCGAN (6.09M参数): 中等规模，FID最低 (351.53)
   - Diffusion (15.72M参数): 最大规模，Precision最高 (0.81)

2. 收敛速度对比:
   - VAE: 快速收敛 (5 epochs, Loss从193→115)
   - DCGAN: 中等收敛 (20 epochs, Loss稳定在3.5左右)
   - Diffusion: 最快收敛 (5 epochs, Loss从0.31→0.04)

3. 图像质量分析:
   - DCGAN: 生成图像最清晰、最多样化
   - Diffusion: 生成图像最稳定、Precision最高
   - VAE: 生成图像较模糊，但重建质量尚可

4. 模式崩溃检测:
   - DCGAN多样性从0.6975提升至0.8830
   - 无明显模式崩溃现象
   - G/D Loss均衡，训练稳定

5. 训练效率:
   - VAE训练最快 (简单架构)
   - Diffusion训练中等 (UNet架构较复杂)
   - DCGAN训练最慢 (需要G/D对抗训练)

================================================================================
附录: 技术细节
================================================================================

A. 损失函数
  - VAE: BCE + KL散度
    BCE = -Σ(x·log(x_hat) + (1-x)·log(1-x_hat))
    KL = -0.5·Σ(1 + log(σ²) - μ² - σ²)
  
  - DCGAN: 二元交叉熵
    D Loss = -Σ[log(D(real)) + log(1 - D(G(z)))]
    G Loss = -Σ[log(D(G(z)))]
  
  - Diffusion: 均方误差
    Loss = MSE(ε_pred, ε)
    其中 ε 是添加的真实噪声

B. 评估指标
  - FID = ‖μ_r - μ_g‖² + Tr(Σ_r + Σ_g - 2(Σ_r Σ_g)^(1/2))
    基于Inception v3特征的分布距离
  
  - IS = exp(E[D_KL(p(y|x) || p(y))])
    基于Inception v3预测的熵
  
  - Precision = TP / (TP + FP)
    生成样本中"真实"的比例
  
  - Recall = TP / (TP + FN)
    真实样本中被生成覆盖的比例

C. 数据集预处理
  - MNIST: 仅ToTensor (0-1范围)
  - CIFAR-10: Resize(32) + ToTensor + Normalize(0.5, 0.5, 0.5)
  - MNIST-3ch: Resize(32) + Grayscale(3ch) + ToTensor + Normalize
  - Diffusion: Resize(32) + ToTensor + Normalize(0.5, 0.5, 0.5)
