# LLM优化实验报告

**日期**: 2026-08-05 17:18

## 1. 概述

验证Prompt工程、RAG、量化三种优化技术在医疗问答场景的效果。

- **模型**: TinyLlama-SFT-merged (1.1B参数)
- **数据集**: MedQA (40条医疗问答样本)
- **设备**: NVIDIA GeForce RTX 5060 Laptop GPU

## 2. Prompt工程实验结果

| 策略 | 准确率 | 幻觉率 | 正确/总数 |
|------|--------|--------|-----------|
| Zero-Shot | 0.00 | 0.45 | 0/20 |
| Few-Shot | 0.20 | 1.00 | 4/20 |
| CoT (思维链) | 0.00 | 0.60 | 0/20 |
| Self-Consistency | 0.00 | 0.60 | 0/20 |

**分析**:
- Few-Shot策略取得了最好的准确率(20%)，说明示例学习对医疗问答有帮助
- 所有策略的幻觉率都较高(0.45-1.00)，说明模型生成的回答质量有限
- CoT和Self-Consistency策略在小模型上效果不佳，可能因为推理链太长导致偏离答案
- Zero-Shot策略准确率为0，说明模型在没有示例的情况下难以直接给出正确答案

## 3. RAG实验结果

| 指标 | 值 |
|------|-----|
| 准确率 | 0.00 |
| 忠实度 | 0.00 |
| 检索文档数 | 5 |

**分析**:
- RAG回答出现重复循环（生成重复文本），说明模型在长上下文生成时存在问题
- 关键词检索成功找到了相关文档，但生成阶段未能有效利用检索内容
- 需要优化生成参数（如repetition_penalty）和prompt模板

## 4. 量化实验结果

| 指标 | 值 |
|------|-----|
| 状态 | 失败 |
| 原因 | CUDA后端不支持动态量化 |

**分析**:
- PyTorch动态量化在CUDA上不可用，需要使用CPU或切换到torchao API
- 建议使用bitsandbytes库进行4位/8位量化，专为GPU设计

## 5. 结论与建议

### 主要发现
1. **Prompt工程**: Few-Shot示例学习对小模型最有效，建议使用2-3个高质量示例
2. **RAG**: 检索功能正常，但生成阶段需优化（增加repetition_penalty、调整温度等）
3. **量化**: 需使用GPU友好的量化方案（如bitsandbytes的NF4量化）

### 优化建议
1. **提升准确率**: 
   - 使用更专业的医疗prompt模板
   - 增加示例数量到3-5个
   - 对生成结果进行后处理（提取选项字母）

2. **降低幻觉率**:
   - 增加系统提示角色约束
   - 设置停止词（遇到A/B/C/D立即停止）
   - 使用repetition_penalty防止重复

3. **优化RAG**:
   - 使用sentence-transformers进行语义检索而非关键词匹配
   - 增加chunk大小和重叠
   - 优化生成参数（do_sample=True, top_p=0.9）

4. **量化方案**:
   - 使用`pip install bitsandbytes`
   - 采用4位NF4量化 + 双精度混合
   - 参考QLoRA方案进行参数高效微调
