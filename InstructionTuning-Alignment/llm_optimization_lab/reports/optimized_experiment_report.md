# LLM优化实验报告（优化版）

**日期**: 2026-08-05 18:52

## 1. 实验概述

本实验针对Zero-Shot和CoT策略准确率低的问题，采用以下优化方案：

1. **Prompt工程优化**
   - 明确的角色设定（资深临床医生）
   - 结构化输出格式约束
   - 输出格式引导：最后必须写"答案：X"

2. **答案提取优化**
   - 正则匹配多种答案格式模式
   - 优先匹配明确的"答案：X"标签
   - 多模式回退机制（行末、标点、频次统计）

3. **生成参数优化**
   - repetition_penalty=1.1 抑制重复
   - CoT策略温度=0.3 增强多样性
   - 自洽性多路径投票

4. **新增策略**
   - Tree-of-Thought (ToT) 多分支思维
   - Self-Consistency 多路径投票
